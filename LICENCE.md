## 🧩 About

**Space Engineers catalog Client** is a curated list of Space Engineers open-source tools:

- **Overlays** — on-screen helpers, layout notes, block info viewer, grid manager
- **Quality-of-Life Helpers** — inventory catalog, blueprint manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize block and grid hitboxes
- Replay Notes — record and review survival runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Block Catalog — browse blocks, colors, skins, effects
- Custom Skin Notes — organize player cosmetics
- Solid Grid Trail — improved grid visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-game
- Jump Buffer Notes — chain complex maneuvers in the editor
